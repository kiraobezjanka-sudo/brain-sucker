# Brain Sucker: Outbreak — документация проекта

Этот файл является главным оглавлением и набором обязательных инструкций для дальнейшей работы над проектом.

## Основные инструкции

- Работать только с файлами внутри текущей папки проекта.
- Не добавлять сторонние JavaScript- или CSS-библиотеки без прямой просьбы пользователя.
- Сохранять существующий survival-horror стиль и основные игровые механики.
- Не удалять существующие возможности без прямой просьбы пользователя.
- После изменения логики запускать автоматические тесты.
- После визуальных изменений проверять игру в браузере.
- Перед публикацией выполнять сборку и проверять отсутствие ошибок.
- Не сохранять ключи, пароли, токены и другие секреты в файлах проекта.
- Не создавать новый публичный сайт при обычном обновлении игры — использовать существующий проект Sites.
- При каждом изменении кода, интерфейса, документации, тестов, сборки или публикации автоматически обновлять корневой `CHANGELOG.md` в рамках того же изменения.

## Как пользоваться документацией

Перед изменением проекта необходимо прочитать этот файл и разделы, относящиеся к задаче. Например:

- изменение механики — `RULES.md`, `CONTROLS.md`, `TECHNOLOGY.md` и `TESTING.md`;
- изменение меню — `INTERFACE.md` и `VISUAL_STYLE.md`;
- изменение музыки — `AUDIO.md`, `INTERFACE.md` и `TECHNOLOGY.md`;
- публикация — `DEPLOYMENT.md`;
- изменение структуры проекта — `TECHNOLOGY.md` и `DEVELOPMENT.md`.

При изменении поведения или структуры игры нужно одновременно обновить соответствующий файл документации.

`CHANGELOG.md` обновляется всегда, даже если изменение касается только документации или служебных файлов. Новые записи добавляются в раздел `В разработке` под подходящим заголовком: `Добавлено`, `Изменено`, `Исправлено`, `Удалено` или `Безопасность`.
