# Сборка и публикация

## Публичный сайт

Текущий адрес:

<https://brain-sucker-outbreak.bobegoha.chatgpt.site>

Публичный проект уже существует. При обычном обновлении нельзя создавать новый сайт или менять адрес.

## Конфигурация

Файл `.openai/hosting.json` содержит идентификатор существующего проекта Sites.

В нём запрещено хранить:

- токены;
- пароли;
- ключи API;
- временные данные авторизации;
- переменные окружения.

## Сборка

Сборка выполняется файлом `build.mjs` и создаёт папку `dist`.

Ожидаемые файлы:

```text
dist/client/index.html
dist/client/styles.css
dist/client/game.js
dist/server/index.js
```

## Процесс публикации

1. Запустить автоматические тесты.
2. Выполнить сборку.
3. Убедиться, что необходимые файлы находятся в `dist`.
4. Зафиксировать точное состояние исходников.
5. Загрузить это состояние в существующий репозиторий Sites.
6. Подготовить архив из той же версии исходников.
7. Сохранить новую версию существующего сайта.
8. Опубликовать сохранённую версию с текущим публичным уровнем доступа.
9. Дождаться статуса успешной публикации.
10. Открыть итоговый публичный адрес.

## Требования безопасности

- Авторизационные данные должны использоваться только временно.
- Токены нельзя записывать в Git-конфигурацию, URL удалённого репозитория или файлы проекта.
- Публичный доступ не следует менять без прямой просьбы пользователя.
- Не публиковать версию, если тесты или сборка завершились с ошибкой.
