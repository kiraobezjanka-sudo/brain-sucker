# Тестирование

## Автоматические тесты

Файл `test-game.cjs` проверяет:

- начальное состояние;
- управление стрелками;
- управление WASD;
- работу WASD при русской раскладке;
- запрет мгновенного разворота назад;
- поглощение образца;
- начисление очков;
- увеличение длины;
- переход через горизонтальные границы;
- переход через вертикальные границы;
- столкновение с собственным телом;
- паузу по `Escape`;
- отсутствие движения во время паузы;
- продолжение по повторному `Escape`.

## Обязательная проверка после изменения логики

1. Проверить синтаксис `game.js`.
2. Запустить `test-game.cjs`.
3. Исправить все ошибки.
4. Повторить тест до успешного завершения.

## Браузерная проверка

После визуальных или интерактивных изменений проверить:

1. главное меню;
2. кнопку `ЗАПУСК`;
3. правила;
4. настройки;
5. размер и читаемость текста;
6. управление WASD;
7. управление стрелками;
8. экранный геймпад;
9. меню паузы;
10. продолжение по `Escape`;
11. возврат из правил и настроек в правильное меню;
12. переход через границы карты;
13. рост и начисление очков;
14. проигрыш при столкновении с телом;
15. отсутствие ошибок в консоли браузера.

## Адаптивность

При изменении интерфейса дополнительно проверить:

- широкий экран;
- узкий мобильный экран;
- отсутствие горизонтальной прокрутки;
- доступность всех кнопок;
- прокрутку правил и настроек при нехватке высоты.

## Критерий готовности

Изменение считается готовым только если автоматические тесты проходят, браузер не показывает ошибок, а затронутый сценарий работает полностью.
