# Музыка и звук

## Общий подход

Игра использует оригинальный процедурный survival-horror саундтрек. Музыка создаётся в браузере через Web Audio API и не копирует мелодии из существующих игр.

Внешние аудиофайлы и сторонние библиотеки не используются.

## Музыка во время игры

После нажатия `ЗАПУСК` начинается бесконечный тревожный эмбиент:

- низкие синусоидальные дроны;
- тихий отфильтрованный шум;
- редкие диссонансные двухголосные импульсы;
- медленное нарастание громкости.

Музыка должна создавать напряжение, но не заглушать интерфейс и будущие звуковые эффекты.

## Пауза

При открытии меню паузы музыка не обрывается полностью, а становится значительно тише. После продолжения исходная громкость плавно восстанавливается.

## Смерть

При столкновении с собственным телом основная музыка затихает и запускается короткая завершающая тема:

- нисходящая последовательность;
- низкий удар;
- быстрое затухание;
- продолжительность около двух секунд.

## Настройки

В настройках находится кнопка `МУЗЫКА` со значениями `ВКЛ` и `ВЫКЛ`.

- При выключении все активные музыкальные источники останавливаются.
- При включении во время игры музыка запускается заново.
- При включении на паузе музыка запускается с пониженной громкостью.

## Ограничения браузера

Браузеры запрещают автоматическое воспроизведение звука без действия пользователя. Поэтому аудиоконтекст создаётся только после нажатия `ЗАПУСК` или кнопки музыки в настройках.
