# Технологии и структура файлов

## Технологии

- HTML5;
- CSS3;
- Vanilla JavaScript;
- Canvas 2D;
- Web Audio API;
- Node.js для сборки и тестов;
- OpenAI Sites для размещения.

Сторонние библиотеки не используются.

## Структура проекта

### `index.html`

Основная разметка:

- корпус терминала;
- информационная панель;
- Canvas;
- главное меню;
- меню паузы;
- правила;
- настройки;
- экранный геймпад.

### `styles.css`

Содержит:

- оформление терминала;
- стили Canvas-контейнера;
- главное меню;
- меню паузы;
- досье правил;
- настройки;
- кнопки;
- геймпад;
- адаптивные стили;
- эффекты старого монитора.

### `game.js`

Отвечает за:

- состояние игры;
- запуск, паузу, продолжение и перезапуск;
- движение;
- управление;
- еду, рост и счёт;
- сквозные границы;
- столкновение с телом;
- отрисовку карты и существ;
- переключение интерфейсных панелей.
- усиленную процедурную фоновую музыку, звук подбора красного глаза и завершающую тему.

Объект `window.SnakeGame` предоставляет методы:

- `reset()`;
- `start()`;
- `pause()`;
- `resume()`;
- `step()`;
- `setDirection()`;
- `getState()`;
- `setFoodForTest()`;
- `setSnakeForTest()`.

### `test-game.cjs`

Автоматические тесты игровой логики без запуска настоящего браузера.

### `build.mjs`

Создаёт папку `dist` с клиентскими файлами и серверной точкой входа для Sites.

### `package.json`

Основные команды:

```text
npm run build
npm test
```

### `.openai/hosting.json`

Содержит только идентификатор существующего проекта Sites. Секретные данные в этом файле запрещены.

### `.gitignore`

Исключает сборочные файлы и временные архивы публикации.

### `AGENTS.md`

Главное оглавление документации и обязательные инструкции для работы над проектом.

### `CHANGELOG.md`

История всех значимых изменений. Файл обязательно обновляется вместе с любым изменением проекта.

### `docs/`

Тематическая документация проекта.

Файл `docs/AUDIO.md` описывает музыкальную систему и правила работы звука.

## Сборочный результат

Команда сборки создаёт:

- `dist/client/index.html`;
- `dist/client/styles.css`;
- `dist/client/game.js`;
- `dist/server/index.js`.
