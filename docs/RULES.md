# Правила игры

1. Игра начинается только после нажатия кнопки `ЗАПУСК` в главном меню.
2. После запуска Brain Sucker автоматически движется по лабораторному сектору.
3. Игрок может менять направление движения с клавиатуры или экранного геймпада.
4. На свободной клетке карты появляется биологический образец.
5. При поглощении образца игрок получает 10 очков.
6. После каждого поглощения Brain Sucker становится длиннее на один сегмент.
7. Нельзя мгновенно развернуться в противоположную сторону относительно текущего направления.
8. Все четыре границы карты являются сквозными:
   - выход справа переносит существо налево;
   - выход слева переносит существо направо;
   - выход сверху переносит существо вниз;
   - выход снизу переносит существо вверх.
9. Столкновение с границей не завершает игру.
10. Столкновение головы Brain Sucker с собственным телом завершает текущую попытку.
11. Во время паузы существо не двигается, счёт не меняется и игровая логика не выполняет шаги.
12. После проигрыша игрок может запустить новую попытку.
13. Цель игры — набрать максимальный индекс заражения, то есть максимально возможный счёт.

## Начисление очков

- Один поглощённый биологический образец: `+10` очков.
- Дополнительные бонусы и штрафы отсутствуют.

## Условия проигрыша

Игра заканчивается только при столкновении головы существа с его собственным телом.

Прохождение через края карты разрешено и не считается столкновением.
