# Brain Sucker: Outbreak

Пиксельная survival-horror игра на основе классической «Змейки».

## Как играть

- Запустите игру кнопкой «ЗАПУСК».
- Управляйте Brain Sucker клавишами WASD или стрелками.
- Поглощайте биологические образцы: каждый приносит 10 очков и увеличивает длину существа.
- Границы игрового поля сквозные.
- Не сталкивайтесь с собственным телом.
- Нажмите `Escape`, чтобы поставить игру на паузу.
- Клавиша `R` перезапускает раунд.
